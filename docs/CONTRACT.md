# Harness Compatibility Contract

Status: v4 release contract.

Daily work uses repository instructions and native tools directly. This optional, explicit-only skill preserves old invocation links without adding a router, readiness gate, classification, plan or checklist. Missing delivery records do not stop independent analysis or repair. Protected-domain authority and user changes remain binding.

Release evidence exercises real tasks in isolated fixtures, including incomplete delivery, authorization, continuity, execution and proportional checks. It binds package, runner, cases and repository instructions. Package validation checks paths, versions and executable evidence; it does not require particular prose.

The plugin releases independently. Template delivery belongs to the source-owned interface and its optional Template Sync skill. The compatibility manifest describes supported delivery contracts, not a daily startup dependency.
