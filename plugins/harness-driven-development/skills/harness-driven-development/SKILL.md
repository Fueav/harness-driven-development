# Harness Compatibility

Use the repository's nearest `AGENTS.md`, relevant project contracts and native tools to complete the requested outcome. Daily work needs no delivery audit, workflow classification or separate Harness checklist. A missing or stale scaffold record does not block independent work.

Run the relevant required checks and report the observed result. Preserve protected-domain approval and user changes. If the requested operation is template delivery, use its source-owned interface; do not turn ordinary work into an upgrade.
