# Routing evaluation evidence

The 2026-09-07 Astra review used independent, expectation-blind routing simulations against the Skill and scaffold instructions. `results.json` records reviewed decisions and proposed verification, normalized for the existing schema; it does not claim those commands ran or establish comparative model performance.
Review the raw request in `cases.json` before judging a result. `stop` refers to the blocked operation; safe preparation or authorized repair can continue. A request to prepare deployment supplies no deployment authorization.
Package digests bind these assessments to the evaluated Skill. Release validation checks schema, coverage, routing, and required evidence descriptions; real delivery/readiness and native tests are proven separately by Scaffold Suite Conformance.
